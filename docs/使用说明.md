# 网站更新指南（使用说明）

本仓库是个人主页的源码，托管在 GitHub Pages。日常更新内容有两条路径：**可视化后台（推荐）** 或 **直接改文件**。改完保存后，GitHub 会自动重新构建并发布，约 1–2 分钟生效。

## 一、内容都在哪里

| 要改的东西        | 文件位置                          | 用什么方式       |
| ----------------- | --------------------------------- | ---------------- |
| 首页 / 各栏目页   | `_pages/` 下的 `.md` 文件         | 后台或改文件     |
| 邮箱 / ORCID 等   | `_data/socials.yml`               | 后台或改文件     |
| 中文页的专利/软著 | `_data/intellectual_property.yml` | 后台（推荐）     |
| 首页"代表作"      | `_data/homepage_publications.yml` | 后台或改文件     |
| 论文列表          | `_bibliography/papers.bib`        | 只能改文件       |
| 图片              | `assets/img/`                     | 后台上传或改文件 |
| 站点全局设置      | `_config.yml`                     | 只能改文件       |

## 二、方式 A：可视化后台（推荐）

1. 打开 **`https://yangyang-li.github.io/Homepage/admin/`**
2. 首次使用需登录。建议用 **GitHub 个人访问令牌（PAT）**：
   - 打开 <https://github.com/settings/personal-access-tokens/new>
   - Name 填 `Sveltia CMS`，Repository access 选 **Only select repositories** → 选 `yangyang-li/Homepage`
   - Permissions → **Contents: Read and write**（其余保持默认）
   - 生成后把令牌粘贴到后台登录框
3. 登录后在左侧选择要编辑的内容（Pages / 社交链接 / 专利 / 代表作）
4. 改完点 **Save**，后台会自动向仓库提交（commit），GitHub 随即自动重建发布

> 注意：编辑"Pages"时，正文最顶部的 `<style>` 主题样式块**不要改动**，只改它下面的正文文字。

## 三、方式 B：直接在 GitHub 网页改文件

1. 打开对应文件（例如 `_pages/chinese.md`）
2. 点铅笔图标 ✏️ 编辑
3. 改完点 **Commit changes**，直接提交到 `main` 分支
4. GitHub 自动重建发布

适合熟悉 Markdown 的人，改动更精确。

## 四、新增 / 修改论文

论文列表由 `_bibliography/papers.bib`（BibTeX 格式）驱动，后台暂不支持，需手动改文件：

1. 复制一条已有的 `@article{...}` 或 `@inproceedings{...}` 记录，改成新论文
2. 每条的 `key`（如 `liFocusingRelevantResponses2024`）必须唯一
3. 若要让论文出现在**首页"代表作"**，把该 key 加到 `_data/homepage_publications.yml` 对应分组

## 五、上传图片

在后台的图片字段里可直接上传，图片会保存到 `assets/img/`。也可以手动把图片放进 `assets/img/`，然后在正文用：

```markdown
![说明文字](/assets/img/文件名.jpg)
```

## 六、本地预览（可选）

```powershell
bundle install
bundle exec jekyll build
```

生成的 `_site/` 目录已加入 `.gitignore`，不会被提交。

## 七、常见问题

- **改了没生效？** 看仓库的 **Actions** 标签，构建失败会有红色 ✕。常见原因是 Markdown/YAML 语法错误，回滚即可。
- **分享卡片（og 图）不显示？** 已在 `_config.yml` 配好 `og_image`；改图后分享平台有缓存，可过段时间再看。
- **想换域名 / 接管根目录？** 目前站点发布在 `https://yangyang-li.github.io/Homepage/`。之后若把仓库改名为 `yangyang-li.github.io` 以接管根目录，需把 `_config.yml` 里的 `baseurl: /Homepage` 改回 `baseurl:`（留空），并记得旧仓库先改名留存。
- **正文顶部 `<style>` 是什么？** 每页的主题样式（配色、背景、字体），属于设计细节，不要删改。
